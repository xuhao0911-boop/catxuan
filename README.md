# CatXuan 0.1

独立的猫类图鉴，沿用 CanisXuan 的手机优先界面，无需注册。

## 当前功能

- 48 个猫种与家猫类型，包含介绍、外形、性格、照护和资料来源；家猫类型单独标记。
- 72 个原创插画外观，每个现有毛色／被毛分型选项均有匹配图片。包含 9 个多毛色条目、5 个可切换长短毛的条目。这些是已绘示例，不代表猫种与毛色已经全部收全。
- 搜索、别名和毛色组合检索、体型／被毛／活跃程度／来源筛选。
- 详情内收藏、最多三个猫种对比；首页卡片无爱心、无毛色数量，猫名和体型居中。
- 五题选猫助手：使用资料的定性编辑标签筛选并解释理由，不套用犬种量表，不生成匹配百分比。
- 分享卡：保留当前选中的毛色和分型，网页可导出 1080×1440 PNG，原生端通过系统分享面板发送图片。
- 资料纠错、实际接收回执、断网保留与重试、反馈历史及本地处理工具。
- 相机／相册与设备内照片分析。当前通用模型仅有波斯、暹罗、埃及猫及虎斑等少量粗粒度类别；虎斑是花纹，不证明纯种血统。照片不上传，基础模型随应用打包，不依赖外部下载。

## 启动

首次使用 Node 24 执行 `npm ci` 和 `npm run export:web`，再启动预览。双击“启动预览.cmd”会检查服务、等就绪后打开浏览器。

本机预览：http://127.0.0.1:4179/?v=0.1。CanisXuan 继续使用 4178。

开发时 npm ci，运行 npm start。生成预览：npm run export:web。也可运行 npm run serve 在终端启动本地预览。

项目使用 Expo 57／React Native 0.86；包内含源码与导出的 Web 预览，不是签名 APK／IPA，也未发布微信小程序。

## 数据与资料

收藏、对比和选猫偏好使用 CatXuan 独立存储标识。犬版数据和应用标识不共用。

猫种资料参考 CFA、TICA 的逐猫种页面；特殊遗传问题额外链接 OMIA。照护与性格标签为编辑归纳，实际表现依个体而异，没有协会数值评分。

插画由内置 image_gen 原创生成，PNG 原稿保留在工作区；项目包包含切好的运行 JPEG。清单：design/generated-art.json；原始格图任务：design/art-jobs.json。

## 反馈服务

当前服务仅监听 127.0.0.1。主动提交的纠错保存在 .catxuan-data/，不公开提供记录列表。可通过 CATXUAN_DATA_DIR 指定私有存储目录；运行日志保存在 .catxuan-runtime/。

原生端通过 EXPO_PUBLIC_CAT_FEEDBACK_URL 配置正式 HTTPS 接收接口；无接口或断网时保留待提交状态。只有收到有效回执才显示已提交。正式对外服务还需域名、HTTPS、持久化部署与平台上线。

查看反馈：npm run feedback:list。
标记核对：node tools/feedback.mjs resolve 反馈ID。
导出反馈：node tools/feedback.mjs export 反馈.json。

## 仓库中的图片

已包含压缩后的完整配图和离线识别模型。图片不缩小，绘图原稿保留在本地；路径与原稿校验见 ASSET-MANIFEST.json。导出后的 dist/ 不纳入源码仓库，请先运行 npm run export:web。
